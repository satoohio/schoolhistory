# Инструкция по бесплатному хостингу

## Рекомендованный стек (всё бесплатно)

| Сервис | Что делает | Бесплатный лимит |
|---|---|---|
| **Render** | Запускает Node.js сервер | 750 часов/мес, авто-деплой из GitHub |
| **Neon** | База данных PostgreSQL | 0.5 ГБ, без ограничений по времени |
| **Cloudinary** | Хранение загружаемых фото | 25 ГБ, навсегда |

Итого: **0 ₽/месяц** при объёме фотографий до 25 ГБ.

---

## Шаг 1 — Neon (база данных PostgreSQL)

### 1.1 Создать аккаунт
1. Перейдите на [neon.tech](https://neon.tech)
2. Нажмите **Sign Up** → войдите через GitHub или Google
3. Нажмите **Create a project**
4. Введите название: `school-db`, регион выберите `AWS EU Frankfurt` (ближайший к России)
5. Нажмите **Create project**

### 1.2 Получить строку подключения
1. В дашборде откройте вкладку **Connection Details**
2. В разделе **Connection string** скопируйте строку вида:
   ```
   postgresql://user:password@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
3. **Сохраните её** — она понадобится на шагах 3 и 4.

---

## Шаг 2 — Cloudinary (хранение фотографий)

### 2.1 Создать аккаунт
1. Перейдите на [cloudinary.com](https://cloudinary.com)
2. Нажмите **Sign Up For Free**
3. Заполните форму или войдите через Google

### 2.2 Получить ключи
1. В дашборде вы увидите блок **Product Environment Credentials**
2. Скопируйте три значения:
   - **Cloud name** (например: `dxxxxxx`)
   - **API Key** (числа, например: `123456789012345`)
   - **API Secret** (строка, например: `abcDEFghiJKL...`)
3. Сформируйте `CLOUDINARY_URL` в формате:
   ```
   cloudinary://API_KEY:API_SECRET@CLOUD_NAME
   ```
   Пример:
   ```
   cloudinary://123456789012345:abcDEFghiJKL@dxxxxxx
   ```
4. **Сохраните эту строку** — она понадобится на шаге 4.

## Шаг 4 — Render (хостинг Node.js сервера)

### 4.1 Создать аккаунт
1. Перейдите на [render.com](https://render.com)
2. Нажмите **Get Started** → **Sign up with GitHub**
3. Авторизуйте Render доступ к вашему GitHub

### 4.2 Создать Web Service
1. В дашборде нажмите **+ New** → **Web Service**
2. Выберите репозиторий `schoolhistory` → нажмите **Connect**
3. Заполните настройки:

| Поле | Значение |
|---|---|
| **Name** | `school-website` |
| **Region** | Frankfurt (EU Central) |
| **Branch** | `main` |
| **Runtime** | `Node` |
| **Build Command** | `npm install && npm run build` |
| **Start Command** | `node server/index.js` |
| **Instance Type** | `Free` |

4. Нажмите **Advanced** → **Add Environment Variable** и добавьте все переменные:

| Key | Value |
|---|---|
| `DATABASE_URL` | Строка из Neon (шаг 1.2) |
| `CLOUDINARY_URL` | Строка из Cloudinary (шаг 2.2) |
| `JWT_SECRET` | Любая длинная случайная строка, например: `school_jwt_secret_key_2024_xK9mP2` |
| `NODE_ENV` | `production` |

5. Нажмите **Create Web Service**

### 4.3 Дождаться деплоя
- В логах вы увидите процесс сборки (3–5 минут)
- Когда появится `==> Your service is live`, деплой завершён
- Ваш сайт доступен по адресу: `https://school-website.onrender.com`

## Шаг 5 — Инициализация базы данных

После первого запуска сервер **автоматически создаст** все таблицы и начальные данные.

Проверьте это:
1. Откройте `https://school-website.onrender.com/api/health`
2. Должно вернуть: `{"ok":true}`
3. Откройте `https://school-website.onrender.com` — сайт работает

## Автоматический деплой при обновлении кода

Render автоматически перезапускает сайт при каждом `git push origin main`.

Процесс обновления:
```bash
# Внесли изменения в код
git add -A
git commit -m "Описание изменений"
git push origin main
# Render автоматически пересоберёт и задеплоит сайт
```

## Частые вопросы

### Сайт не открывается сразу после деплоя
На бесплатном тарифе Render «засыпает» после 15 минут неактивности. При первом обращении после сна сайт запускается **10–30 секунд**. Последующие обращения — мгновенные.

### Как избежать «засыпания»
Используйте бесплатный сервис [UptimeRobot](https://uptimerobot.com):
1. Зарегистрируйтесь бесплатно
2. Добавьте монитор: `https://school-website.onrender.com/api/health`
3. Интервал: 5 минут
4. Сайт больше не будет засыпать

### Как привязать свой домен (например, school1.ru)
1. Купите домен (REG.RU, TimeWeb и др.)
2. В Render откройте Settings → Custom Domains → Add Custom Domain
3. Пропишите в DNS у регистратора CNAME-запись на адрес Render
4. Render автоматически выдаст SSL-сертификат

### Фотографии не отображаются после обновления кода
Если вы не настроили Cloudinary — фотографии хранятся временно. С Cloudinary фотографии хранятся **навсегда** независимо от деплоев.

## Стоимость при превышении лимитов

| Сервис | Бесплатно | Если нужно больше |
|---|---|---|
| Render | 750 ч/мес (хватает) | $7/мес за постоянный сервер |
| Neon | 0.5 ГБ БД | $19/мес за 10 ГБ |
| Cloudinary | 25 ГБ фото | $89/мес за 225 ГБ |

Для школьного сайта бесплатных лимитов хватит на **годы**.
